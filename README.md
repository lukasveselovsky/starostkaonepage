# starostkaonepage

Jednostránková kampaňová stránka pre Evu Veselovskú, kandidátku na starostku obce Liptovská Lúžna.

Postavené na React + Vite + Material UI (MUI), s vlastnými fontami (Fraunces / Manrope) a parallax efektom v hero sekcii.

## Vývoj

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Výstup sa vygeneruje do priečinka `dist/`.
